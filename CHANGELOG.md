# Changelog

## 0.1.0.dev0 — first public development preview

- Extract the native joint-feedback implementation into an installable package.
- Include fixed request, bounded decoder/poller, probe, benchmark, receiver and optional display.
- Include offline transport/parser/freshness tests and fabricated packet fixtures.
- Publish sanitized timing data from one stationary and one pendant-pose hardware experiment.
- Document known protocol facts, provenance, privacy transformations and unsupported scope.
- Final review: explicit virtual-environment instructions, preconnection local-file
  checks, malformed-display handling, optional-Tk help and manifest-checked archives.

This is an unofficial compatibility profile with
one tested configuration. Native movement, operation-permission diagnosis,
arbitrary I/O access, controller programs and SDK redistribution are excluded.
Source publication does not imply a stable package release or PyPI publication.
